## 1. General Description

This project consists of a PPM P6 to PPM P3 file converter and its visualization.

The objective of this project was to learn and improve the following topics:
- Manual manipulation of binary and text image files.
- P6 → P3 conversion without relying on external libraries.
- Use of Tkinter + Pillow to display images.
- Processing of lists, tuples, and linear data to represent images.
- Code modularization and terminal calls.
- Debugging bytes, integers, and file formatting.

| Files | Responsibilities |
